# SteadyMind

**Steady Your Mind Past The Storm**

SteadyMind is a personalized anxiety, focus, confidence, and resilience app prototype.

## Current Prototype Includes

- Updated SteadyMind branding
- Step progress indicator
- Multi-select improvement assessment
- Challenge question
- Time commitment question
- Hope outcome question
- Personalized dashboard response

## Disclaimer

SteadyMind is a wellness and self-support tool. It is not a replacement for professional medical advice, diagnosis, therapy, or treatment.
