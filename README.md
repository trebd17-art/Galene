# SteadyMind v5

**Steady Your Mind Past The Storm**

This version adds the post-assessment functionality:

- Personalized Profile
- Mind Type
- Primary Path and Supporting Focus
- Daily Dashboard
- Gamified XP / Mind Points
- Levels
- Weekly Review screen

Main tracks:
- Calm & Anxiety
- Overthinking
- Confidence
- Focus
- Stress & Burnout
- Motivation
