# Galene

**Find your calm beyond the storm.**

Galene is a personalized anxiety and resilience app prototype designed to help users manage anxiety, improve sleep, build confidence, and develop long-term emotional resilience.

## Current Prototype Includes

- Welcome page
- Learn more page
- Create account / sign in screen
- Privacy Policy and Terms links
- Personal anxiety assessment
- Calm dashboard
- Mobile-style design

## Disclaimer

Galene is a wellness and self-support tool. It is not a replacement for professional medical advice, diagnosis, therapy, or treatment.
