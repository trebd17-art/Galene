# Twelve educational videos — review copies

These videos are on the review branch, not the live app. Open an MP4 link and
use **Download raw file** if GitHub does not offer playback.

All narration follows the submitted scripts verbatim. These versions use the
latest soft, conversational neural voice and pace, full-HD illustrations,
a brown lead character and varied supporting characters, clear visible captions,
optional WebVTT captions, gentle transitions, and no background music.

Each closing slide contains its requested closing message, reference titles,
and this shared footer:

> SteadierMind provides general wellness education, not diagnosis or individualized treatment.
